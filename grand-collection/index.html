What is in the Grand file

The zip Pirates-of-Ybor-Grand-2026-11-12.zip and the GitHub branch are organized the same way.

1 · Play-now site

The newest build (Nov 12): all games, the music engine, cinematic openings, Flex Grotto, and the open world with Plunder & Heat, lasers and the Sandbar projector. Ready to upload to a web host.

2 · Ybor Cay open world (Nov 11)

The stand-alone open world with boxing, police, GPS and extras. Kept beside the site so nothing from it is lost.

3 · App and store build

The app version of the site with accounts, the Supabase database files, the iPhone and Android wrapper, and the store listing, setup and upload guides.

4 · Artwork

The Treasure Ship picture in JPG and WebP.
